SEGATA SAKURA — version 0.2.0 bêta

Cet installateur contient l'application, Kronos 2.7.0 et ses bibliothèques. Aucune installation préalable de Kronos n'est nécessaire.

Windows 10/11 64 bits. Le composant Microsoft Visual C++ inclus sera proposé si nécessaire ; cette étape peut demander une autorisation administrateur.

Les jeux et le BIOS Saturn ne sont pas inclus. Après installation, choisissez votre BIOS dans Configuration puis cliquez sur Ouvrir un jeu ou + Dossier.

La désinstallation conserve vos réglages personnels. Version non signée, testée sans partie réelle : les performances dépendent de Kronos et de votre matériel.
