# Segata Sakura 0.2.2 beta

- Fixed the transparent Windows icon by rebuilding a multi-resolution ICO from the existing Sakura artwork (16, 24, 32, 48, 64, 128 and 256 pixels).
- Embedded the corrected icon in the executable and installer. Shortcuts explicitly reference a new icon filename to avoid the previous cached resource.
- Added a settings panel with Interface, Game folders, BIOS, Graphics and filters, Audio and Controller categories, translated into all five application languages.
- Added Kronos image filters: bilinear, bicubic, adaptive and Bob deinterlacing, and scanlines.
- Added HQ4x, 4xBRZ and 6xBRZ upscaling, internal resolution, aspect ratio, VSync and FPS options.
- Added audio volume, recursive folder scanning and automatic library minimization during gameplay.
- Preserve unrelated Kronos INI settings, back up modified INI files, detect conflicting edits and roll back if saving application settings fails.
- The installer remains in English. Kronos is bundled unchanged. No games or BIOS are included.

Validation: application tests cover filter IDs from the UI, INI persistence and preservation, conflicting edits, failed-save rollback, language navigation and existing library checks. The executable icon decodes correctly. Isolated installation and upgrade checks are recorded separately. Gameplay effects, sound, controller compatibility and installation on a clean Windows system remain unverified. Unsigned beta; existing third-party notices still apply.
