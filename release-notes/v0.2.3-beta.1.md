# Segata Sakura 0.2.3 beta

- Integrated player 1 controller editor: capture keyboard keys, mouse buttons, USB buttons, hats and axes without opening Kronos settings.
- Editable keyboard (Mednafen), AZERTY, keyboard/mouse, Saturn mouse, PlayStation 1–5 and Xbox presets. USB profiles use SDL mappings for the connected device; unknown adapters require manual binding.
- New installations start with the keyboard preset. Upgrades preserve existing controller mappings.
- Horizontal volume slider, percentage, mute/restore and reset controls.
- Japan, USA and Europe BIOS slots, automatic CUE/ISO header selection and a configurable fallback for CHD/unknown regions. No BIOS included.
- Unlimited fast-forward option using Kronos' VSync/frame limiter. Default in-game shortcut: F4. No fixed speed multiplier.
- Flag badges beside the five application languages, independent of Windows emoji rendering.
- First-run BIOS page includes all three regional slots.

Tests cover regional BIOS selection and persistence, input code encoding, an SDL virtual controller (button/hat/axis capture and preset bindings), slider persistence and previous UI/library/configuration checks. No physical-controller compatibility or real-game testing is claimed. The installer remains English-only and unsigned. Kronos 2.7.0 is unchanged.

Keyboard mapping reference: https://mednafen.github.io/documentation/ss.html
Mouse support reference: https://docs.libretro.com/library/beetle_saturn/
