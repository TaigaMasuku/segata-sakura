# Segata Sakura 0.2.1 beta

- English-only installer with a welcome page and explicit installation steps.
- UTF-8 BOM installation information to fix broken accented characters.
- First-run assistant: language, BIOS, game folders, controller, display and summary.
- Five application languages: English, French, Spanish, Portuguese (Portugal), Portuguese (Brazil).
- Settings can reopen the assistant and change the language.
- BIOS and games may be configured later. Existing settings are preserved.
- Kronos controller/video settings remain in its own window and language.

Validation: nine checks pass, including five-language wizard navigation, cancellation, persistence, legacy settings migration and existing CUE/library checks. Isolated silent installation and tests of the installed executable pass. This does not validate gameplay, controllers, audio or installation on a clean Windows machine. The installer remains unsigned.

Kronos 2.7.0 is bundled unchanged. Games and BIOS are not included. Existing third-party notices and distribution qualifications still apply.
