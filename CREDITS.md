# Crédits

## Segata Sakura

**Interface modifiée et clarifiée, intégration et présentation par Taiga Masuku, alias Théo M.**

Développement d'une interface C# propre au projet : bibliothèque, scan, vérification des CUE, choix des dossiers, configuration et lancement du moteur ; installateur et site. Le binaire Kronos 2.7.0 est embarqué sans modification. Aucun code DuckStation n'est intégré.
